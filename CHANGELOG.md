# Changelog

All notable changes to the Ambient Focus Overlay project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.1] - 2026-10-14
### Added
- **Interactive Task Edit Feature**: Added ✏️ edit button on every task item that opens an in-place tactile edit modal to change task title, scheduled date, and target deadline time without losing timer progress.
- **Upgraded Premium App Logo**: Designed and generated high-resolution neumorphic forest-sage icon (`icon.png` & `icon.ico`) with golden compass star emblem matching the app's aesthetic.

## [1.1.0] - 2026-10-14
### Added
- **Multi-Date History & Future Planning**: Date navigator with `‹` and `›` controls and calendar date picker to view past logs and schedule upcoming tasks.
- **Overdue Red Flags (🚩)**: Automatic detection of tasks past their set deadline time with prominent red flag alert indicators.
- **Random Timer Check-ins (5m - 12m)**: Configurable non-predictable check-in intervals to prevent procrastination.
- **Active Browser Distraction Guard**: Native process and window monitor that detects when social/video sites (YouTube, Facebook, Instagram, Twitter, Netflix, etc.) are active during a focus block.
- **Silent Windows Startup**: Created `Launch-Silent.vbs` and registered Windows startup shortcut for seamless zero-terminal autostart on boot.

## [1.0.0] - 2026-10-14
### Added
- Initial release of Ambient Focus & Productivity Desktop Overlay.
- Tactile Neumorphic design system with Forest Sage and Cream color palette.
- Frameless, transparent floating window with Always-on-top and Desktop-pin modes.
- Collapsible floating pill with active task indicator and ticking stopwatch.
- Interactive To-Do list with individual task stopwatches and prominent global STOP button.
- GitHub-style 18-week contribution heatmap tracking completed tasks and focus minutes.
- Mindful accountability check-ins ("Are you on track?") with distraction counter and motivational quotes.
- Persistent local notes scratchpad with zero cloud dependency.
- Windows auto-start toggle and 1-click batch launcher (`Launch-Overlay.bat`).
